# Bellabeat Smart Device Usage Analysis

## Project Overview
This project analyzes Fitbit fitness tracker data to explore how people use smart devices to track their daily activity, steps, calories, and sleep patterns. The goal is to identify trends that could help Bellabeat improve its products and marketing strategies.

## Business Task
Analyze smart device usage data to identify activity and sleep patterns and develop recommendations for Bellabeat's marketing strategy.

## Tools Used
- Python
- Google Colab
- Pandas
- Matplotlib
- Kaggle dataset

## Key Findings
- Average daily steps: **6,547**
- Average daily calories burned: **2,189**
- Average sedentary time: **995 minutes**
- Average sleep duration: **6.99 hours**
- Approximately **43.1%** of daily records fell into the low-activity category.

## Recommendations
1. Encourage users to set achievable daily step goals.
2. Promote consistent daily movement and reminders to reduce sedentary time.
3. Encourage healthier sleep routines and greater awareness of sleep habits.
4. Use personalized activity insights to improve user engagement.

## Data Source
Fitbit Fitness Tracker dataset, available on Kaggle. The dataset contains activity and sleep information collected in 2016.

## Limitations
The dataset is relatively old and represents a limited number of participants. Only 12 participant-date records matched between the activity and sleep datasets, so reliable conclusions about the relationship between activity and sleep cannot be drawn.

## Conclusion
This analysis demonstrates how fitness tracker data can reveal useful patterns in daily activity and sleep. The findings can help inform data-driven marketing recommendations for Bellabeat's smart wellness products.
